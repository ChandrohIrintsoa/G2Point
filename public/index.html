G2Point

Posez un point à tour de rôle sur les intersections. Encerclez les points adverses avec une chaîne de vos points pour les capturer.

Duel : deux joueurs se relaient.

Préparation de la connexion en ligne…

Pour jouer en ligne, configurez votre projet Firebase en suivant le fichier README.md, puis rechargez cette page. Le jeu local fonctionne sans configuration.

Créez une partie puis partagez le code à 5 caractères. Vos amis ouvrent le même site, choisissent le même mode et saisissent ce code.

Règles du jeu
  • Un seul point par tour, chacun son tour. Rouge commence.
  • Bonus : quand vous capturez des points adverses, vous rejouez aussitôt un point supplémentaire. Une capture par piège ne donne pas de bonus.
  • Pour capturer, formez une boucle fermée de vos points, reliés en ligne, en colonne ou en diagonale. Les bords du terrain ne ferment pas une boucle.
  • Chaque point capturé vaut 1 point et reçoit une croix.
  • Piège : si vous posez un point dans une zone vide déjà entourée par l’adversaire, il est capturé, sauf s’il permet de capturer à son tour.
  • À 3 ou 4 joueurs, chacun joue pour soi. En mode équipes, les joueurs 1 et 3 affrontent les joueurs 2 et 4.
  • La partie s’arrête quand le terrain est plein ou lorsqu’un joueur termine la partie. Le score le plus élevé gagne.
  • Le chat est disponible uniquement dans une partie en ligne. Choisissez un pseudo sans information personnelle sensible.
